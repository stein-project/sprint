# Sprint 0.1.0: toggle sprint and toggle sneak, with your state on the HUD

Sprint holds the game's sprint or sneak key for you with one press, and shows on the HUD what you are doing. It comes with the Stein Client.

- **Toggle Sprint** (G) and **Toggle Sneak** (no key by default): the mod only holds the game's key, so the game still decides when you sprint (forward only, hunger, items in use, blindness) and the server sees exactly what it would see from a player holding the key.
- **Your state on the HUD**: `[Sprinting (Toggled)]`, `[Sneaking (Key Held)]`, `[Flying + Sprinting (Toggled)]`, `[Descending (Toggled)]` and `[Riding]`, in three text styles. By default it shows only what is happening; it can also show the toggle while you stand still.
- **Double-tap forward** can be turned off, so tapping W in a fight no longer starts a sprint by accident.
- **Stop sneaking when you start flying**, and the game's own sprint and sneak keys can toggle too.
- **Your Combat key comes along**: toggle sprint used to live in Combat. On the first start, Sprint brings over whether it was on and the key you had chosen.
- **Servers can turn either toggle off** (`toggleSprint`, `toggleSneak`).
- **Needs Stein Loader 0.1.35**: update with the installer before the mod.
